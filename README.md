# if 的个人博客

你好，我是 **if** —— 一名正在学习后端与大模型的开发者，在这里记录我的项目实践、学习笔记与日常随想。

## 板块结构

- **首页**：个人简介、精选项目、我的学习方向、最新文章、近期随笔与推荐
- **项目**：展示在学大模型、Agent 与后端过程中做的开源实践项目与工具
- **学习**：技术长文、学习总结与项目复盘（支持 Markdown 与代码高亮）
- **随笔**：几句话的日常思考、今日所学、跑步/听歌/游戏生活片段
- **推荐**：平时收藏的优质教程、开源项目与实用工具
- **关于我**：个人介绍、爱好与快捷发布入口

## 怎么在网页/手机上发布新内容

本仓库已配置好 **GitHub Issues 模板** 与 **GitHub Actions 自动构建**：

1. 打开本仓库的 **Issues → New issue**
2. 选择对应的模板：
   - **📝 发布学习文章 / 笔记**（自动带 `文章` 标签）
   - **💬 发布随笔 / 动态**（自动带 `随笔` 标签）
   - **🔖 添加推荐 / 书签**（自动带 `推荐` 标签）
3. 填写内容（支持直接粘贴上传图片）并提交，GitHub Actions 会在约 30 秒内自动构建并更新到博客网页（仅读取 `ifhgh666` 本人创建的 Issue）。
4. 也可以直接在线编辑 `content/seed.json` 修改个人简介、项目列表与初始内容。
